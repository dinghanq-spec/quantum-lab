ALGORITHM 01 / DECISION PROBLEM

Deutsch-Jozsa

決定性與平衡函數的躍升

1 QUERY
問題背景

黑箱函數到底是哪一種？

給定一個輸入為 $n$ 位元的黑箱函數 $f(x)$，我們保證它不是「常數函數」，就是「平衡函數」。常數函數對所有輸入都輸出相同結果；平衡函數則恰好一半輸出 0、一半輸出 1。

傳統最壞情況\[2^{n-1}+1\]次查詢
→
Deutsch-Jozsa1次量子查詢
01
INITIALIZE

準備兩條量子線

輸入暫存器從全零開始，輸出位元準備成 $|1\rangle$：

\[ |0\rangle^{\otimes n}|1\rangle \]

$\otimes n$ 表示 $n$ 個 $|0\rangle$ 的張量積。

02
SUPERPOSITION

H 閘展開所有問題

對每個位元施加 Hadamard，輸入同時走過全部 $2^n$ 條路徑：

\[ H^{\otimes n}|0\rangle^{\otimes n}=\frac{1}{\sqrt{2^n}}\sum_x|x\rangle \]

每個輸入 $x$ 都以相同振幅出現。

03
ORACLE

神諭造成相位回踢

Oracle 計算 $f(x)$，輸出位元的相位把資訊「踢回」輸入狀態：

\[ U_f|x\rangle|{-}\rangle=(-1)^{f(x)}|x\rangle|{-}\rangle \]

輸出 1 的路徑會多一個負號，形成干涉線索。

04
MEASURE

H 閘後讀出答案

再次施加 $H^{\otimes n}$，相位干涉會讓答案集中在 $|0\rangle^{\otimes n}$ 或其他狀態。

\[ f\text{ 常數}\Rightarrow 0^n\qquad f\text{ 平衡}\Rightarrow \text{不是 }0^n \]

一次 Oracle 查詢，就能分辨兩類函數。

DJ
WHY IT MATTERS

量子優勢來自干涉，不只是「同時試很多次」。

疊加產生所有路徑，Oracle 寫入相位，最後的 Hadamard 讓錯誤方向互相抵消、正確分類留下訊號。

ALGORITHM 02 / SEARCH PROBLEM

Grover 搜尋

非結構化資料的平方根加速

O(√N)
問題背景

在一堆沒有線索的資料裡找目標

若資料沒有排序或結構，傳統搜尋平均要檢查 $N/2$ 個項目。Grover 演算法用 Oracle 標記目標，再用平均值反轉放大它的振幅。

傳統搜尋$O(N)$逐項檢查
→
Grover 搜尋$O(\sqrt{N})$量子迭代
01
PREPARE

建立均勻疊加

對 $n$ 個輸入位元施加 H 閘，讓每個資料索引都有相同機率：

\[ |s\rangle=\frac{1}{\sqrt{N}}\sum_{x=0}^{N-1}|x\rangle \]

起點是整個搜尋空間的平均狀態。

02
ORACLE

標記目標項

Oracle 不直接告訴我們答案，而是只把目標態的振幅反相：

\[ |w\rangle\mapsto -|w\rangle \]

這個負號就是接下來干涉的材料。

03
AMPLIFY

平均值反轉放大

Diffusion operator 以平均振幅為鏡面反射，讓目標振幅變大、其他振幅變小：

\[ D=2|s\rangle\langle s|-I \]

Oracle + D 合稱一次 Grover 迭代。

04
ROTATION

幾何旋轉後測量

把狀態想成由「平均態」轉向「目標態」的平面旋轉：

\[ k\approx\frac{\pi}{4}\sqrt{N} \]

做太多次反而會越過目標，迭代次數要剛剛好。

G
GEOMETRIC INTUITION

每次迭代都像把箭頭轉向答案。

所有狀態其實可壓縮成「目標」與「非目標」兩個方向。Oracle 先翻面，Diffusion 再反射，合起來就是固定角度的旋轉。

ALGORITHM 03 / NUMBER THEORY

Shor 因數分解

把破解大數轉成尋找週期

RSA THREAT
核心概念

因數分解很難，但週期可能很有規律。

Shor 的巧妙之處，是把「找出 $N$ 的質因數」改寫成「找出模冪函數的週期」。量子電腦用 QFT 讀出週期，再把週期轉回因數。

傳統最佳已知方法次指數時間仍是超多項式
→
Shor 演算法多項式量子週期尋找
週期尋找的主角
\[ f(x)=a^x\pmod N \]

當 $a$ 與 $N$ 互質時，某個最小正整數 $r$ 會讓 $a^r\equiv1\pmod N$。這個 $r$ 就是函數重複的週期。

$N=15, a=2$2, 4, 8, 1, 2, 4, 8, 1, ...因此 $r=4$
01
CLASSICAL SETUP

先選數字，先做輾轉相除

隨機選 $a$，其中 $1<a<N$，先算最大公因數：

\[ d=\gcd(a,N) \]

若 $d>1$，不用量子電腦就找到因數；若 $d=1$，繼續找週期。

02
MODULAR ARITHMETIC

建立模冪函數

觀察指數 $x$ 變化時的輸出，函數會因模 $N$ 而循環：

\[ f(x)=a^x\bmod N \]

這把數論問題轉成找出重複間隔。

03
QFT

用量子傅立葉變換找週期

QFT 把週期波形轉成頻率峰值，從測量結果推回 $r$：

\[ \mathrm{QFT}_M|x\rangle=\frac{1}{\sqrt M}\sum_{y=0}^{M-1}e^{2\pi ixy/M}|y\rangle \]

白話：QFT 像量子頻譜分析儀，找出資料裡的節奏。

04
FACTOR

週期轉回因數

若 $r$ 是偶數，計算兩個最大公因數：

\[ p=\gcd(a^{r/2}-1,N),\quad q=\gcd(a^{r/2}+1,N) \]

$N=15,a=2,r=4$ 時，可得到 $\gcd(3,15)=3$ 與 $\gcd(5,15)=5$。

S
CRYPTOGRAPHY CONNECTION

為什麼這會威脅 RSA？

RSA 的安全性依賴大數因數分解很難。Shor 能有效率地找週期，進而取得因數，因此未來需要後量子密碼學。
